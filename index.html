What this tool does

This planner helps you manage offline work setup schedules, track WFO/WFH outcomes, monitor WFH credits, review flagged entries, and export reports for selected employees and periods.

How to use it

  • Use the Schedule view to create, edit, and monitor employee rows.
  • Use WFO Summary to review flagged entries and their next-week reflected dates.
  • Use WFH Credits to track available credits earned from weekly WFH activity.
  • Use Dashboard to review charts and contributor activity.
  • Use Generate Report to export employee data for the selected date range.
